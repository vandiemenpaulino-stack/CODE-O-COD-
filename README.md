# Simple Code Samples

Ten small programs in ten different languages/formats.

| File | Type | Run with |
|------|------|----------|
| 01_guess_game.py | Python | `python 01_guess_game.py` |
| 02_fizzbuzz.js | JavaScript | `node 02_fizzbuzz.js` |
| 03_index.html | HTML | Open in browser |
| 04_style.css | CSS | Used by the HTML page |
| Temperature.java | Java | `javac Temperature.java && java Temperature` |
| 06_factorial.c | C | `gcc 06_factorial.c -o fact && ./fact` |
| 07_calculator.cpp | C++ | `g++ 07_calculator.cpp -o calc && ./calc` |
| 08_greet.sh | Bash | `bash 08_greet.sh` |
| 09_students.sql | SQL | `sqlite3 < 09_students.sql` |
| 10_profile.json | JSON | Data file |
